# Wie sehen Kind- und Eltern-Oberfläche aus?

Type: prototype
Status: open
Blocked by: 04, 06

## Question

Wie sehen die Bildschirme aus? Kindgerät: Restzeit groß, Start/Stopp, heutiges Kontingent, Zustand „Überziehung“. Elterngerät: heutiger Stand, Wochenvorlage bearbeiten, Tagesausnahme setzen, Verlauf, Geräte koppeln. Ein grober klickbarer Prototyp dient zum Reagieren und soll „native-like“ wirken.
